# kollab-cli skill

Terminal-agent instructions for Kollab CLI 0.1.25: workspace resources, Hosted
Apps, API keys, and managed text, image, video, audio and 3D tools.

```bash
npx skills add KollabTeam/Kollab@kollab-cli
pnpm add -g kollab@0.1.25
kollab login
```

Automation can use an account API key for supported standalone commands; see
[the skill](SKILL.md) and [standalone API](references/standalone-api.md).
Reinstall/update the skill to receive new instructions; updating the CLI alone
does not update installed skill files. Preserve local customizations first.
